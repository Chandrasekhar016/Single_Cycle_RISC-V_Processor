# Single_Cycle_RISC-V_Processor
## Overview
A 32-bit single-cycle RISC-V processor implemented
using Verilog HDL and Xilinx Vivado 2025.2.

## Features
- Hierarchical RTL design
- Program counter and instruction memory
- Register file and immediate generator
- Main control and ALU control
- Arithmetic Logic Unit (ALU)
- Data memory and write-back logic
- Simulation and synthesis-based validation
